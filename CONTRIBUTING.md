# 🤝 Cómo contribuir a CASID

## Licencias
- **Código fuente**: [GNU AGPLv3](LICENSE)
- **Documentación y diseños**: [CC-BY-SA 4.0](LICENSE.DOCS)

Al enviar un Pull Request, aceptas que tu contribución se distribuya bajo estas licencias.

## Flujo de trabajo
1. Haz fork del repositorio
2. Crea una rama descriptiva (`feat/`, `fix/`, `docs/`)
3. Realiza commits atómicos y claros
4. Abre un PR vinculando el issue/objetivo relacionado
